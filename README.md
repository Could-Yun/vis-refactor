# 《可视化导论》课程网站重构

> 《可视化导论》课程作业：保留老师原有的五章教学内容，重建课程门户、章节导航和演示入口，让内容**更好找、更好读、更连得起来**。

**在线访问（GitHub Pages）：<https://could-yun.github.io/vis-refactor/>**

原课程网站：<https://cinger007.github.io/vis/>（仓库 `cinger007/vis`）。教学正文、关键代码、数据集与讲义均来自原课程，作者与授课教师信息保留在门户和页脚。

## 为什么重构

重构前先在浏览器里逐页检查原站，学习上的障碍集中在三处：

| 障碍 | 原站情况 | 本次做法 |
|---|---|---|
| **找不到** | 没有搜索；门户只链接 5 个章节，补充 Demo 从首页无法到达 | 全站搜索 + Demo 集合并入门户导航 |
| **读不动** | 单章页面很长，读到哪、还剩多少都不知道 | 侧边目录高亮 + 阅读进度 + 继续上次阅读 |
| **连不起来** | 五章之间没有总览，理论分散在各章的“嵌入理论”框里 | 课程知识地图 + 图表选型工具 |

原则是**只改承载方式，不改教学内容**：正文、理论框、代码、数据和 Demo 都保留，章节划分不变，便于和原站逐项对照。

## 主要功能

| 功能 | 说明 |
|---|---|
| **全站搜索** | 覆盖五章小节与 Demo，共 306 条索引（中英各 153 条）。中文用二元组切分、零依赖；支持 `Ctrl + K` 打开、方向键选择、回车直达、`Esc` 关闭 |
| **阅读支持** | 粘性侧边目录随滚动高亮当前小节，顶部进度条显示本章位置，页脚提供上一章 / 下一章 |
| **学习进度** | 浏览器本地记录已访问的小节；门户章节卡显示进度环，“继续阅读”回到上次的小节。记录只代表访问情况，不代表掌握程度 |
| **中英双语** | 门户、章节外壳与讲义正文都可切换，切换时停留在原位置 |
| **Demo 集合** | 原站 14 个补充 Demo 按章节整理成画廊，每个附对应小节与一句说明 |

## 新增的四个交互可视化

1. **课程知识地图**（门户）：力导向图，5 个章节节点 + 25 个核心概念节点，连线表示前置依赖。悬停突出前置链路，拖动调整位置，点击跳到对应小节。
2. **Mackinlay 通道排序**（第 2 章）：替换原来的静态排序图。切换定量 / 有序 / 名义三种数据类型，通道优先级和排序理由同步变化。
3. **图表选型工具**（门户，并接入第 1、2、4 章）：选择字段类型组合，联动给出分析任务、推荐图表（条形图、散点图、折线图、直方图、热力图）、预览和理由，并链接回相关章节。
4. **色彩感知对比器**（第 3 章）：同一份数据并排渲染 jet、viridis、RdBu，叠加相对亮度曲线；可切换灰度和三类色觉缺陷的近似模拟，直观看出 jet 带来的“假边界”。

## 修复的问题

- 补充 Demo 页引用了仓库中不存在的样式表，线上没有样式：改为统一样式。
- `volumeRendering.html`、`yearcalendar.html` 两个链接指向不存在的文件（线上 404）：移除，并在 Demo 集合页说明原因。
- 章节到 Demo 的深链锚点全部失效：改为稳定的语义锚点（如 `lesson-01/#ch-1-3`）。
- `regression.html` 原为白页（只加载了 d3-regression，没有加载 d3 本体）：补全为可拖动散点、实时更新拟合线与 R² 的回归演示。
- D3 混用多个 CDN 且未锁版本（含 `@latest`）：D3 7.9.0 与 d3-regression 1.3.10 本地化，许可证随 `assets/vendor/` 保留。
- 英文模式下门户和章节外壳仍有中文残留：补齐 i18n 词条。
- 删除全站无引用的数据文件；第 2 章 444 KB 的排序 PNG 改为交互 SVG。

## 课程内容

| 章 | 主题 | 主要内容 |
|---|---|---|
| 第 1 章 | 数据 | 数据生成、DIKW 金字塔、Stevens 测量尺度、Mackinlay 视觉通道、D3 数据变换、Data-Join 三态；附 5 个小 Demo |
| 第 2 章 | 数据可视化流程 | Card 数据流模型、新生数据 → 分类树 → 树形列表、Reingold-Tilford 布局、DOM 事件机制 |

| 第 5 章 | 时序数据可视化 | 时间属性、人名时间序列、van Wijk 日历热图、阿基米德螺旋日历、Storyline 故事线 |

每章页面分“讲解 / 关键代码 / 演示”三个标签页；`lectures/` 保留每章的中英文讲义 Markdown。

## 目录结构

```
vis-refactor/
├── index.html              课程门户：搜索、知识地图、图表选型、章节卡
├── lesson-01 … lesson-05/  五章页面（index.html + lesson.js）
├── demos/                  补充 Demo 集合（index.html 为画廊）
├── lectures/               各章中英文讲义
├── assets/
│   ├── css/                core / features / i18n / demos / 各章样式
│   ├── js/                 portal.js、features.js（搜索 / 目录 / 进度）、i18n.js
│   │   └── charts/         knowledge-map / mackinlay / chart-chooser / color-compare
│   ├── data/               课程数据集
│   └── vendor/             本地化的 D3 7.9.0、d3-regression 1.3.10 及许可证
├── search-index.json       搜索索引（由 build_search.py 生成）
└── 重构方案.md              重构前的问题清单与设计方案
```

## 本地运行

纯静态网站，无需安装依赖：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

## 构建与检查脚本

| 脚本 | 作用 |
|---|---|
| `build_search.py` | 重建全站搜索索引 `search-index.json` |
| `qa_site.py` | 浏览器回归测试：检查站内链接、逐页脚本报错与资源 404，以及搜索、进度等交互（需要 Python Playwright 与 Edge） |
| `qa_portal_layout.py` | 检查门户的“继续阅读”与进度面板，以及中英文、桌面 / 手机宽度下导航居中、无横向滚动、进度环不压住状态徽标 |
| `build_deliverables.py` | 生成课程要求的说明文档与源码压缩包，输出到 `交付物/`（该目录不入库） |
