# 可视化导论课程重构

原课程：https://cinger007.github.io/vis/

发布：https://could-yun.github.io/vis-refactor/

运行：`python -m http.server 8080`，访问 http://localhost:8080/。

功能：五章课程、双语讲义、全站搜索、学习进度、知识地图、通道排序、图表选型、色彩对比及 Demo 画廊。D3 7.9.0 与 d3-regression 1.3.10 已本地化。

`交付物/` 含文档、演示讲稿和验收报告。`qa_site.py` 需要 Python Playwright 与 Edge，用于浏览器回归测试。
